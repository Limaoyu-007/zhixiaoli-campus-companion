# 开发对话日志与统一设置

2026-10-27更新。日志供开发排障使用，独立于学生长期记忆和平台会话。只有开启后的操作会写日志，不补录历史对话。

## 设置保存

设置窗口改为分类导航：校园对话、通用学习、学习通、长期记忆、我的课表、形象与显示、回复朗读、开发调试。固定底栏只有一个“保存更改”，统一保存所有配置、本次编辑的学生资料、近期事项和课表。

切换分类保留输入；未保存有明确提示，关闭窗口时提醒。四组API Key独立配置，在设置页明文回显；清空并保存即删除，不从环境变量或其它模块回退。先在前端检查手动资料格式，再写配置；如果配置写入成功而资料落盘失败，明确显示部分保存，保留未保存的资料修改。没有将多文件保存宣称为原子事务。

“立即整理”“清空记忆”“重新读取资料”属于即时操作，使用次级按钮；立即整理遇到未保存修改时先走统一保存流程。课表编辑与识别配置直接在设置页；识别只生成草稿，点击统一保存后生效，识别前仅保存自己的模型配置。

## 开启与查看

1. 重新启动源码程序，在“设置 → 开发调试”查看当前实际日志状态。
2. 源码启动默认开启，打包安装默认关闭；已保存的 `debug.enabled` 优先于默认值，示例配置显式关闭。切换后点击“保存更改”。
3. 复现一轮对话。点击“打开日志目录”直接查看，或“导出调试日志”另存JSONL，交给开发人员分析。

目录为 `app.getPath('userData')/logs/`。Windows源码版通常是 `%APPDATA%\open-desktop-pet\logs\`。

当前文件 `campus-dialogue.jsonl`，约5MB轮转，保留 `.1`、`.2` 两份旧文件，总共最多3个；导出按最旧到最新合并。每行是一条JSON记录，可用编辑器搜索同一个 `requestId`，并通过 `sessionId`、`conversationId`关联会话。旧日志中的密钥在导出时再次按当前已知凭据脱敏。

## 记录内容

- `chat.received`：用户原始提问、会话和请求标识。
- `memory.prepared` / `memory.failed`：新会话记忆准备是否成功、是否实际注入、所用整理模型和错误；`memory.state`另记后台整理状态、待处理数量、资料数量和最后错误，不记录整个整理请求。
- `memory.request` / `memory.request-failed` / `memory.request-completed`：整理模型的接口域名/路径、模型、Key来源及格式布尔值、HTTP状态、百炼错误码/请求ID及耗时。没有Key明文或错误响应原文。401单独提示鉴权问题，核对地域/套餐配套关系，不再笼统提示额度。
- `chat.context`：实际发给学校平台的query，包含本轮生效的记忆/课表文字和当前时间，可用来排查“她是否收到资料”。
- `platform.http`：HTTP状态、响应类型；`platform.tool`记录工具名、解析后的输入、业务success/code与简要状态。不记录完整原始工具返回、密码、思考文本或SSE原文。
- `platform.message-end`：平台消息标识和usage（如返回）。回复格式错误、会话标识不匹配、证书不匹配也有对应事件。
- `chat.completed`：显示给用户的回复、业务反馈、告警、耗时。
- `chat.failed` / `chat.cancelled`：失败阶段、原因、耗时及远端操作是否仍不确定。
- `timetable.parse.*`：识别开始、完成或失败，模型、页数、耗时、课程数量和警告；不记录图片/PDF字节。
- `settings.saved` / `settings.failed`、`session.new`、`app.started`：辅助区分配置保存、会话切换和程序启动。

耗时以该轮收到提问为起点累计，记忆准备和平台等待均计入。日志不会改变预约成功判定、重试策略或业务授权；日志写入失败不阻塞正常对话，在开发调试页提示写入错误。

## 数据边界

日志会保留对话文字、姓名/专业等背景、预约号及工具参数，供用户明确要求的本机开发分析。API Key、Authorization、常见密码/Token字段、带标签的密码文本，以及当前配置的凭据做脱敏；不采集图片、原始SSE、思考过程或任意HTTP请求头。脱敏不等于完全匿名，导出分享前仍需检查个人信息或没有标签的敏感文本。

没有自动上传、后台反馈、分析模型调用或云端日志服务。关闭日志后停止新增，已有记录保留；如需移除可以从日志目录删除。导出不会覆盖正在使用的日志及用户数据目录中的核心文件。

代码：`services/campus-debug-log.js`、`main.js`、`services/campus-agent-service.js`、`services/campus-response.js`、`preload.js`、`renderer/campus-settings.*`。打包清单已包括日志服务。
