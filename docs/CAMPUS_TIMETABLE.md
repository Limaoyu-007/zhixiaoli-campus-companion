# 智小理个人课表第一版

2026-10-23。个人课表在本机维护，学校平台的公共通知知识库继续保留。未接入教务系统，不自动根据学校通知变更课程，也未实现课前提醒。

## 使用

1. 重新启动源码程序。右键人物 → **我的课表**，或设置 → **管理我的课表**；托盘菜单也有入口。
2. 进入“设置 → 我的课表”，填写百炼识别配置，点击固定页脚的“保存更改”。默认视觉模型 `qwen3-vl-plus`；Key 和接口地址留空时沿用长期记忆配置。环境变量 `DASHSCOPE_API_KEY` 优先，其次课表专用Key，再其次记忆Key。学校平台Key不会用于识别。课表窗口提供直达配置页的“前往设置”，不再单设配置保存按钮。
3. 导入图片或 PDF，再点击“识别为课表草稿”。支持 PNG/JPG/JPEG/WebP/PDF，单个文件不超过20MB；PDF最多6页，超出请先导出课表页。加密PDF需先自行导出未加密版本。识别最长等待90秒，可停止；不会自动反复重试。
4. 对照左侧原图修改课程。尤其核对星期、起止小节、上课周次、地点；同课不同上课安排分行记录。周次支持 `1-16`、`1-16(单)`、`1-8,10-16`，内部展开为周次数组。
5. 补充第一教学周的**周一日期**、学期总周数和学校的节次钟点。空值表示未知，不会自动填入默认作息或用导入日代替开学日。可以先保存部分资料，缺失项仍提示待补充。
6. 点击“保存课表”。识别成功只更新草稿，保存前原课表仍生效。下一条聊天自动携带最新保存的课表，不必重新建平台会话。也可以不导入文件，直接添加课程和节次手工保存。

识别模型必须支持图片输入、非思考模式、JSON对象输出。接口地址使用百炼控制台所在地域的 OpenAI 兼容地址，支持以 `/chat/completions` 结尾的完整路径。请求中明确要求未识别的信息留空，但模型仍可能识别错误，用户保存前需要核对。

参考：[千问视觉理解](https://help.aliyun.com/zh/model-studio/vision/)、[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)、[PDF.js 用法](https://mozilla.github.io/pdf.js/examples/)。

## 数据流与本地文件

```text
选择图片/PDF → 本地预览（PDF.js逐页渲染PDF）
  → 显式点击识别 → 百炼视觉模型 → 结构化草稿
  → 学生核对/修改 → 保存本地JSON与原文件
  → 每次聊天：北京时间＋教学周＋课表文字＋真实问题 → 学校平台
```

文件位于 Electron `app.getPath('userData')`，并非仓库或平台知识库：

- `campus-timetable.json`：enabled、termName、week1Monday、totalWeeks、periods、courses、notes、updatedAt、source。
- `timetable-source-<随机ID>.<后缀>`：确认保存的那一版原文件。导入时先保留所选文件的字节快照，保存时写入本机，避免外部原文件之后变动。替换原文件成功后删除旧副本。
- `config.json` 的 `timetable` 节点：独立视觉模型配置；Key仅主进程使用，不回传页面，不写文档。

PDF在本地转为图片，图片长边最多2600像素；识别时发送到百炼。学校平台每次只收到文字化的已保存课表，不收到原图片、PDF或百炼凭据。勾选“在校园聊天中使用”控制是否注入；关闭或清空后，下一条消息明确告知平台本条没有有效课表。已经进入平台历史的内容不能从本机撤回，可用“新会话”移除旧会话背景。

## 聊天上下文

- 每条消息提供当前北京时间、星期、第一教学周起点和当前教学周；当前周用日期差计算，第一周之前或已知学期结束之后明确标记。
- 第一版每次附上完整课程列表及节次钟点、核对备注，学校模型处理“明天有什么课”“周五下午是否有空”等提问。不做复杂检索，也不重复解析源文件或额外调用百炼。
- 课程必须同时匹配星期和上课周次。缺少周起始日、周次或节次不能断言无课，钟点不明不能推算具体上下课时间和行程衔接。
- 课表更新仅以用户保存为准。调停课通知不会自动写入；图片文字、课名及备注作为数据处理，不执行其中的指令。
- 长期记忆继续只在新会话首次附上。普通会话记录和后台记忆整理仍使用真实用户问题及助手正文，不把整份课表或图片当作用户聊天重复录入。
- 本地课表读取失败会提示，本轮仅提供当前时间和无有效课表说明，正常校园对话继续。

## 代码入口与边界

- `services/campus-timetable-service.js`：本地文件、源文件快照、百炼视觉提取、保存/清空、聊天背景拼接。
- `services/timetable-utils.js`：主进程和编辑页共享的周次解析、日期/节次规范化、缺失信息提示、北京时间和教学周计算。
- `renderer/campus-timetable.html/js`：独立编辑窗口、原图预览、PDF.js本地渲染、课程/节次编辑、识别配置。
- `main.js`、`preload.js`：窗口、窄IPC、主进程凭据、每次聊天注入；关闭课表窗口或退出取消识别。
- `pdfjs-dist@6.4.299`：仅在无Node集成的渲染页动态加载legacy浏览器构建，worker/字体/CMap/wasm从本地依赖加载，已加入打包文件清单。没有在Electron主进程加载它的Node接口。

本轮完成代码与依赖接入，按用户约定未运行测试、编译构建、桌面验收、真实百炼识别或学校平台对话。文件识别质量、界面体验和平台实际使用课表的效果待用户体验；旧exe不包含此次修改。
