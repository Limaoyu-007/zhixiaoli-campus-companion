# 个人课表

更新：2026-10-27。课表在本机维护，不接入教务系统，不自动根据通知改课，也没有课前提醒。

## 使用

1. 打开设置 → 我的课表；人物右键与托盘的“我的课表”也定位到这一页，不再另开窗口。
2. 在“课表识别配置”独立填写百炼API Key、接口地址和视觉模型。Key明文回显，清空并保存即删除，不借用记忆配置或环境变量。
3. 导入PNG、JPG、WebP或PDF，点击“识别为课表草稿”。点击识别前仅保存识别配置，不提交其它分类未完成的编辑。也可直接手动添加课程。
4. 核对课程、星期、节次、周次和地点。填写第一教学周周一、学期总周数，以及学校每小节的钟点。未知值保留空白，不自动猜测；概览和提示标出待核对资料。
5. 点击底部“保存更改”。识别成功仅产生草稿，保存后才用于聊天。重新读取已保存课表会询问是否放弃当前编辑。

图片/PDF最大20MB，PDF最多6页。源文件在本地转成JPEG，单页长边最多2600像素；识别会把图片发送给独立配置的视觉模型。校园平台只收到文字化的确认表，不收到原图片或视觉模型凭据。

## 数据与查询

数据在app.getPath('userData')：

- campus-timetable.json：开关、学期、第一周日期、总周数、课程、节次、备注、更新时间与原文件元数据。
- timetable-source-*：确认保存的原文件副本。识别时保留所选源文件字节快照，保存成功后替换旧副本。
- config.json的timetable：独立识别配置；API Key仅向设置窗口回显，聊天页及日志不接收明文。

启用后，校园每轮附上当前时间与确认表；通用学习按需通过get_timetable读取。日期按第一周周一换算教学周，课程同时匹配星期和周次；学期外和资料不全会明确提示。缺少周起点、周次或钟点不能推断全天无课、具体时间或行程不冲突。

关闭或清空后不再提供有效新课表背景，但已有远端对话的内容无法从本机撤回，需要时新建会话。备注、课名及识别文件均作为数据，不执行其中的指令。

## 实现与检查

- services/campus-timetable-service.js：源文件快照、视觉识别、保存/清空与校园背景。
- services/timetable-utils.js：日期、周次、教学周、节次规范化与缺失提示。
- renderer/campus-timetable.js：嵌入设置页的编辑器、原图预览与PDF.js转换；CampusTimetableEditor协调草稿、忙碌状态及统一保存。
- main.js/preload.js：仅允许设置窗口调用导入、识别及保存IPC。
