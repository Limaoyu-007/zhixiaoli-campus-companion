## 比赛展示主线

1. 桌面角色承接自然语言输入，选择校园业务或通用学习模式。
2. 校园业务展示既有平台和真实业务工具的连接能力，避免把平台能力都归为本地实现。
3. 通用学习展示自己的 Runtime：理解问题、调用时间/课表/学习通工具，再结合返回值回答。
4. 展示个人课表与共享长期记忆如何使回答与学生个人情况相关。
5. 用明确结果展示完成情况；未取得的数据或未实现能力不作为承诺。

以上是已有能力的叙述提纲，本轮没有另行制作 PPT、录屏或演示数据，也没有再次调用业务系统。

## 保留的技术边界

- 本地 Runtime 是本地编排；模型可以来自云端，不承诺完全离线。
- 学习通当前查询一个指定课程的名称、页面状态和进度；不扫描全部课程、不提供截止时间、不读取/提交作业题目。
- 长期记忆是本机资料/摘要与独立模型整理，不是向量检索知识库。
- 人物为代码驱动二维形变，不是正式 Cubism 模型或三维角色。
- 校园业务仍依赖已有平台部署、授权和工具；其他人克隆源码不会自动获得这些资源。
- 未加入网页搜索、任意文件/Shell 执行或定时自主任务。
